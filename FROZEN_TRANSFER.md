# Frozen integrated-loop transfer evaluation

This bounded evaluation adds twelve input structures, with the existing controller,
world mechanisms, numeric/decision/authority policies and full-session native
retrieval unchanged. Both discovery arms execute selected formulas through actual
pinned-native PLN. Scan is the same cognitive policy with another retrieval path.

Protocol and fixtures: reviews/frozen-transfer-v1/. BASELINE.json distinguishes
publication from actual controller/backend/auditor source identities. The cohort
and independent construction checks were committed before controller execution.
No new parent is a development smoke example. Runtime defects or construction
failures remain attached to their original result rather than silently retuned.

With the original pinned native builds installed, from committed source:

```sh
uv run --no-project python -m transfer_lab.compare run --output /tmp/frozen-transfer
uv run --no-project python -m transfer_lab.compare audit /tmp/frozen-transfer --output /tmp/frozen-transfer-audit
```

The first command runs exactly 24 primary executions, alternating arm order by
parent. It writes source-bound captures, raw queries, frontiers, choices, native
formula receipts, SQLite certificates, physical and recognized trajectories,
per-parent effectiveness diagnostics, parity divergence records and readable
comparison/cost tables. Unresolved outcomes are not conformance failures or
proven correct abstentions. Static conditional derivability does not establish
same-information task feasibility; no optimal planner is added.

The audit retains the original A/B, complete frontier, certified arithmetic,
ancestry, physical recurrence and persisted-state checks. Fresh native discovery
reexecution is counted separately from recorded arithmetic and original native
PLN. Cross-authority parity normalizes only the named authority/binding IDs and
timers in transfer_lab/parity.py; all individual bindings remain checked against
authority and actual receipts. Every retained query is checked against full sources.

```sh
uv run --no-project python -m transfer_lab.validate default --output /tmp/transfer-validation
uv run --no-project python -m transfer_lab.validate native --output /tmp/transfer-validation
```

Full capture, remaining checks, native preparation/guards/load/readback/query,
formulas, certification, persistence, monitoring and elapsed time remain charged.
Nested timers overlap and cannot be added. Logical clock units, physical versus
recognized loss, source/value content, wire bytes and publication size are distinct.
RSS, peak memory, isolated fsync and real sensor latency remain unmeasured.

Archive verification uses the existing review manifest/tar/checksum convention;
recorded-only extracted audit is audit(directory,reexecute=False). It cannot
recreate the original closed sealed runtime generations. No optimization or new
scheduler, pressure/transport, depth, policy promotion or recovery work follows.
