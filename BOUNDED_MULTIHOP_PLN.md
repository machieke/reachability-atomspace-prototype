# Bounded online multi-hop numerical PLN

`experimental_multihop` is a separate experimental extension. It discovers registered
criterion/opposite producers through at most three dependency levels and exposes
only exact, complete current five-premise deduction applications. Templates have
no belief IDs or speculative truth values. Actual committed intermediate revisions
become inputs to subsequent selected certified computations.

The extension reuses the frozen full capture, A/B and one-step validation, then
expands only the old bridge's explicitly deferred deeper-route fragment. It records
that extra work and its cost. The separate consumer preserves the original FIFO,
control/report priorities, attempted-basis identities, budgets and monitoring
headroom. The original bridge/consumer and live admission/execution authority are
unchanged. Original revision interfaces remain regressions, not new discovery work.

The versioned review covers all registered criterion/opposite producers and their
complete upstream AND groups and OR alternatives. New producers invalidate closure.
Cycles, depth-four routes, incomplete captures and exhausted bounds remain incomplete,
even when a current source can fill one slot. Accepted/uncertain actions retain
operational monitoring/reconciliation priority when numerical work is incomplete.

All source/adopted estimates have deduction depth zero; committed deductions add one
to their deepest exact premise. Total call count is separate from longest accepted
path. Exact upstream invalidation and equal-valued replacement use the existing
ledger; old revisions cannot become fresh inputs. Shared ancestry never grants
independence. A complete work graph is neither a decision filter nor a permission.

The evaluator uses the unchanged observable independent world, fixed ticks and
opportunities through the full horizon. Physical time does not wait for reasoning.
Forecasts and accepted deductions never establish physical effects or observed
completion. No new sensor or physical model is introduced.

The six fixtures and their roles, source values, explicit finite joint witnesses,
review depth, events and budgets are preregistered in
`reviews/bounded-multihop-v1/fixtures.json` and `PROTOCOL.md`. Fixture witnesses are
offline checks and never controller inputs. Runtime guarantees remain local to each
selected three-proposition invocation; no general global consistency or calibrated
confidence guarantee follows from serial use.

After the existing pinned native build, run both modes and audit a fresh directory:

```sh
uv run --no-project python -m multihop_lab.compare run --output artifacts/multihop-local
uv run --no-project python -m multihop_lab.compare audit artifacts/multihop-local
```

Missing native dependencies block native validation; finite arithmetic does not
substitute. AtomSpace remains an authoritative-record projection/readback check.
The Python dependency scan is fully charged and makes no native retrieval claim.

The review includes measured public inputs, template graphs, concrete tuples, actual
native calls, all certificates/commits, exact ancestry, invalidation, independent
physical/observed outcomes, costs, failures and omissions. One-hop parity and the
frozen deeper-route capability boundary are tested; completion of tasks outside that
baseline's fragment is not a scheduling-performance victory.

Stop at this bounded publication. More depth, arbitrary backward chaining, confidence
consolidation, new formulas, policy promotion, pressure/transport, delayed/noisy
sensors, effect repair, generalized recovery and native-storage redesign remain
outside scope.
