# Detached decision obligations, experimental v0

Run from a committed checkout with the existing pinned native build:

```sh
uv run --no-project python -m obligations_lab.compare run --output artifacts/obligations-local
uv run --no-project python -m obligations_lab.compare audit artifacts/obligations-local
```

The output directory must be new. The first command runs both shadow interpretations
on eleven finite semantic parent structures (one reused historical native ledger)
and three small native reconstructions. It writes complete immutable captures,
exact declared role manifests, all inspected/witness records, native formula inputs
and outputs, SQLite journals, acquisition/evaluation costs, and a readable decision
table. There is no scheduler sweep and no execution of the counterfactual policy.

A reproduces the unchanged all-current numerical rule. B is a separately declared,
non-authoritative proposal: every mandatory obligation needs adequate evidence;
explicit alternatives may discharge one obligation. Every current strength objection
fails and every current opposite estimate remains unresolved, regardless of confidence.
Unclassified current evidence and missing mandatory support remain unresolved.
An `all` obligation requires every eligible current assessment. A required method
must have its own obligation if absence must block. Source/root restrictions define
eligibility, never statistical independence. Revision parents remain visible/current
as determined by the existing ledger. No confidence aggregation or supersession.

Bounds and exact roles were committed in the preregistration before evaluating B.
Status precedence is FAIL > STALE > UNKNOWN > PASS. Incomplete, malformed, unsupported
or exhausted input cannot PASS. `numerical_status` separates the criterion from scoped
hard checks; `status` also includes scope, registry/provenance and known hard checks.
Neither is an execution authorization. Original permits and intents retain exact
stale-set checks even when new shadow status does not change.

The capture adapter reads complete authoritative exports and frozen private registry
and hard-check seams under the service lock. It retains no service reference. It is
limited to one criterion and the declared finite fragment. It trusts the local checked
authority and does not authenticate arbitrary JSON or prove absence of undiscovered
contradictions. Capture and record bounds close unsupported cases. The independent
reference checks supported complete inputs; diagnostics check unsupported cases
against separately declared outcomes. Audit replays detached assessments, independent
predicates, final SQLite authority, and pinned arithmetic. It checks recorded native
bindings; it does not claim a new native execution during replay.

Tests exercise all Boolean witness patterns up to three real certified reports,
64 status combinations, interval/floor boundaries, all-current parity, hard gates,
nonmutation, exact freshness, missing methods, copied lineage, objections, complete
scans and bounds. Native tests reconstruct weak deduction, revision and adverse
inference. Historical assignments are explicitly counterfactual.

The review bundle contains test inventories, failures, omissions and exact source
bindings. Costs are single-pass descriptive values. Acquisition is charged once
per capture; A/B have separate evaluation times, subdivided into scan, applicability,
policy evaluation and witness serialization. Substage times nest in total evaluation;
setup and parsing/hash work appear in total/residual. Native/session costs are retained
with their existing inclusive definitions. Isolated arithmetic, fsync and RSS are
unmeasured. No old timing or controller result is overwritten.

This is a bounded semantic experiment. The live all-current execution contract
remains authoritative. No policy promotion, changed threshold, new retirement,
recovery automation, transport tuning, or native storage work is included.
