# Native multi-hop retrieval integration protocol

Baseline closure: c4686bc6fb100c324874f12f2f98d66aa2f0e9d7. Frozen scanner,
consumer, fixtures, world and authority remain byte-identical. This protocol is
registered before new implementation or measurement. The handoff is retained.

Run MH-scan and MH-native, each crossed with finite and native PLN formula modes,
over the existing two-hop, three-hop, shared, unavailable, replacement and adverse
parents, in that order. Twenty-four executions represent six parent structures.
Use the exact existing configuration, depth-three review, operation/work/acquisition
budgets, seed, eight slots per tick and nine ticks. No threshold or fixture tuning.
Native retrieval must execute in both formula modes of MH-native.

Use the pinned native backend and complete immutable projection. Query limits:
4096 visits, 512 results, 4096 queries per view; existing graph/source/transport
caps remain. Every changed public binding cold-replaces the view. Same-binding
queries may reuse it. No scan fallback, incremental synchronization or restart
service. Complete empty, explicit bound, malformed/stale view and helper failure
remain distinguishable. Incomplete discovery cannot authorize new work. Existing
accepted/uncertain operation control keeps its priority and budget headroom.

The old one-step validator may calculate its unused graph and that cost is fully
charged. Its computed operation identities, producer routes and applications are
not discovery inputs. The new adapter must obtain discovery membership from native
query responses; full source loading, history validation and unchanged execution
frontier scans are separately identified. Query receipts confer no authority.

Compare semantic work views and choices offline at identical snapshots/history;
independently compare closed-loop sequences after normalizing authority-specific
identities. Record every epoch, query, exact input, source revision and build,
cost, failure, correction and omitted test. Query reexecution, recorded formula
checking, fresh native PLN invocation and SQLite reconstruction have separate
counters. Audit data never enters the controller. A difference is a conformance
defect, not a benefit. Runtime shape/binding checks do not prove completeness
against a malicious helper; independent source scanning detects omissions.

Targeted tests cover causal native use, actual intermediate round trips, stale
and replaced supports, fresh registry insertion, complete AND/shared ancestry,
opposition, bounds and malformed/lost helper, exact typed transport, cycles/depth
four and unchanged execution gates. A few unrelated records test membership only.
Run applicable existing suites and new seam tests once at the measured revision;
record exact executed/omitted IDs. Preserve all earlier review artifacts, failures,
corrections and build receipts, including the historical wrapper exit 143 anomaly.

Costs are descriptive serial measurements. Report full capture, frozen A/B and
validation, native construction/serialization/build/startup/load/readback, epochs,
queries/visits/results, Python traversal/tuple assembly, selection/frontier,
formula/certification/commit/persistence/dispatch/monitoring and total elapsed.
Nested timers are not additive. RSS, peak/native process memory and serialization
copies are explicitly unmeasured unless separately instrumented. A short answer
set does not bound full memory. Logical parity is not real-time speed parity.

Stop after tested native-driven parity/failure semantics and one source-bound
review publication. No policy promotion, adaptive transport, new depth/families,
persistent native storage, scaling, calibration or generalized recovery.
