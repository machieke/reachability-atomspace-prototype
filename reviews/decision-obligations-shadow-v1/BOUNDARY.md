# Interpretation and authority boundary

A is the live contract's universal judgment: every current same-literal estimate
must be in interval and adequate; a current opposite estimate is unresolved. It
fits a task declaring every materialized assessment independently mandatory. The
materialization itself then creates another requirement, which can legitimately
prevent execution after valid reasoning.

B fits a different task declaration: specified assessment obligations may each
have explicitly interchangeable witnesses. Adequate direct support can discharge
one such obligation while an agreeing weak derivation stays visible without
creating a new mandatory requirement. An independently compulsory source or method
needs its own obligation, and missing or inadequate support for it still blocks.
An `all` group requires all currently eligible assessments and at least one;
listing several producer classes in one group does not require an instance of
every listed class. Separate class-presence requirements use separate obligations.

Neither interpretation is selected by terminal success. These are policy
conformance diagnostics, not estimates of false acceptance, false rejection,
real-world safety, or deployment benefit. All new cases leave external effects at
zero and observed outstanding goal loss at ten. Historical roles are explicitly
counterfactual; a new B judgment does not rewrite the old trajectory.

B scans every current relevant record for objections. A same-literal interval
violation fails even at low confidence; any current opposite estimate remains
unresolved. A contrary derived result can invalidate a favorable assessment.
Unclassified evidence stays unresolved. Copied lineage does not satisfy a declared
different source/root requirement and receives no confidence bonus. Parents and
revision children coexist exactly as the original ledger records them.

Source/root selectors express eligibility, not statistical independence. The
constructed revision example uses the existing explicitly registered independence
model and actual certified revision formula. This experiment adds no independence
inference, aggregation, winner selection, supersession, or retirement rule. PLN
confidence retains the pinned evidence-adequacy meaning, not an event probability
or bound on deployment risk.

A complete local authoritative snapshot is a scoped claim about this authority,
not proof that every possible contradiction has been discovered. New fixtures register explicit source identities through the existing public
probability-policy API; captured policy revisions and role manifests remain exact.
The capture
adapter trusts checked local authority and does not authenticate arbitrary JSON.
It reads frozen private registry/hard-check seams under the same lock as public
exports. Unsupported/malformed/partial/exhausted captures cannot yield a shadow
PASS. The output reports separate numerical and scoped-check statuses. Neither
is an execution permit, and typed APIs reject it. No production code imports the
shadow evaluator. Old permits/intents retain exact-set staleness even where a new
numerical judgment or value is unchanged.

No production policy is recommended. Task owners must first resolve the normative
role declarations, trusted applicability and completeness boundaries, treatment of
unclassified sources, model independence assumptions, and contradiction handling.
Calibration and empirical decision quality remain untested. A future alternative
would require a separately versioned live policy, fresh certificates, regression
evidence and review. The existing all-current contract remains authoritative.
