# Representation-invariant pressure projection v1

This is a bounded experimental extension of frozen revision
`3e8fd7be56362ed21944636bbe505b6a4a7aac6f`. The earlier review and all original
implementation/episode files remain unchanged. No cost placement is promoted.

The supported requirement language is finite signed propositional FACT and
idempotent Boolean AND/OR within one context, goal episode, slice and temporal
contract. Normalize only this detached advisory view: eliminate unary operators,
flatten equal operators, sort children and deduplicate identical children.
Do not distribute, absorb different operators, equate proofs, change quantities,
or normalize evidence/resource/temporal predicates into facts. Original authority
contracts and candidate support references still govern certification.

Default projection bounds: 512 input occurrences across at most four goals,
depth eight, 512 children, 512 projected occurrences. Existing public admission
additionally limits each original condition to 128 occurrences and eight children.
Exhaustion raises a structured blocking error containing the unchanged source
accounts; no partial graph, rank or operation is returned. Existing pressure
graph/session/iteration budgets apply afterward. Gamma remains 0.85.

Generate all unary depths 0–8, both AND and OR, and independent fixed-seed
combinations of unary wrappers, same-operator reassociation, order changes and
duplicates over mixed AND/OR trees. Exhaustively evaluate every small truth
assignment using a truth-set oracle independent of runtime normalization.
Compare common real candidates, source ledgers and per-source values at semantic
nodes; numerical allowance is the sum of solver L1 error bounds plus 1e-12.
Report unresolved primary-score ties at that allowance, and preserve the common
cost/identity tie-break. Raw hashes, provenance and runtime need not match.

The comparison has nine policies: unchanged B0, four existing raw cost
placements, and four named `B3-normalized-*` experimental placements. Frozen
`B3-cost-both` is exactly the original B3 path. Run every original episode/seed
(7,18) under every original budget (work-8, work-16, time-100ms, time-500ms).
Separately run every old depth/cost and parallel-cost diagnostic, missing unary
depths and OR wrappers, generated mixed transformation families, and real-work
negative cases under work-8. Policy order rotates per cell; no tuning or training.
The exact generated case inventory is committed with the tool before measurement.

All policies share candidates, budgets, operation charges, hard gates, world
events and the sixteen-tick outcome horizon. Actual certified inference is used.
The runner retains full per-operation ranks, pressure/provenance, observations,
stale replies, external losses and journals; replay checks every selected request.
Normalization, graph construction, numerical solve, discovery, inference,
certification, persistence and elapsed totals are reported separately. Timing is
measured once per cell and is not a significance estimate. Work-limited semantic
invariance is checked separately from wall-cap host-load variation.

Publish source archives, configuration/seeds, test logs, audit and file hashes.
Record favorable, neutral and unfavorable outcomes without requiring a win.
Stop at this contract; no broader normalization, cost-policy promotion, transport,
learned conductance, new duration model or generalized recovery.
