# Bounded online multi-hop numerical PLN

The separate experimental extension discovers short registered numerical dependency
chains, acquires/adopts a missing upstream report, commits intermediate deductions,
and uses those exact revisions in subsequent selected computations. All five ordered
premises and the original certification/commit checks remain mandatory. Actual
product/health observations from the frozen independent world establish observed
completion; inference never supplies physical relief.

The original one-step bridge/consumer, A/B, authority, formulas, native builds and

The [protocol](PROTOCOL.md) and [exact fixtures](fixtures.json) fix six parents,
source/method roles, explicit finite joint witnesses, depth, review roots, event
ordering and budgets before measurement. The new review covers every registered
criterion/opposite producer and all its complete upstream dependencies through depth
three. A template is distinct from an executable tuple and from a committed estimate.
A current result does not conceal another relevant producer. Cycles, deeper routes
and exhausted bounds remain visibly incomplete; no favorable estimate closes a
partial review.

Only dependency discovery and the corresponding experimental work view are extended.
Control/report priorities, FIFO ties, attempted-basis suppression, total budgets and
monitoring headroom are preserved. Supported one-hop deduction behavior is checked for parity;
the old deeper-route boundary is retained. Completing a task outside that baseline's
fragment is not a general scheduling-performance victory.

[COMPARISON.md](COMPARISON.md) gives the finite/native outcomes.
[TRAJECTORIES.md](TRAJECTORIES.md) records actual depths, per-hop values, shared
ancestry, invalidation and lifecycle timing. [COSTS.md](COSTS.md) explains measured
and unmeasured costs. [VALIDATION.md](VALIDATION.md) lists passes, negative checks,
coverage and omissions. [DEVELOPMENT.md](DEVELOPMENT.md) retains exploration,
unfavorable development values and pre-freeze changes separately from measured data.

Sources/adopted estimates count as depth zero. A deduction adds one to the maximum
depth of its exact committed inputs. Total calls, accepted depth, requests, work and
model ticks are different measurements. No intermediate or final estimate is seeded
in the six fixtures, and no harness callback selects a deduction sequence.

The shared joint witness is an offline fixture check. The runtime still certifies
only each selected three-proposition invocation. A serial chain does not establish
a global consistency guarantee, calibrated confidence or production safety. The
adverse branch is a separately scoped estimate family, not a forced reconciliation
into the positive chain's joint model.
